# 精神心理随访本地原型

这是一个 Vite + React 本地网页项目，用于练习“已确诊患者的低负担日常随访”。它不是诊断工具，也不能替代医生评估。

## 本地运行

先安装依赖：

```powershell
npm install
```

启动开发服务器：

```powershell
npm run dev
```

然后打开终端里显示的本地地址，通常是：

```text
http://localhost:5173
```

## 项目文件

- `package.json`：项目脚本和依赖
- `index.html`：Vite HTML 入口
- `vite.config.js`：Vite React 配置
- `src/main.jsx`：React 挂载入口
- `src/App.jsx`：压力监测应用主体
- `src/App.css`：页面样式
- `stress.html` / `stress.js` / `stress.css`：之前的静态版备份

## 当前功能

- 每日低负担记录：睡眠小时、睡眠质量、躯体化/疼痛、今天有没有缓过来一点
- 每日三件自我肯定
- 随心记录
- 树洞板块，预留未来 AI 对话上下文接口
- 每周一次标准化周评
- 日常负荷 0-100
- 最近 30 天趋势图
- 7 日均值、平均睡眠、平均躯体化
- 评分解释
- 数据质量/一致性提示
- 睡眠质量、蓝牙设备、联网同步、App 使用监管接口占位
- 复诊摘要导出
- 本地保存
- CSV 导出
- 示例数据生成

## 科研上的下一步

这个项目目前是练习用原型。后续可以扩展：

- 替换为正式授权量表，并保留版权/授权说明
- 加入肌电 EMG 传感器数据
- 加入语音特征：音高、能量、停顿、语速
- 接入睡眠设备、蓝牙设备和 App 使用时长数据
- 接入 AI 对话，但需要隐私、危机处理和人工复核边界
- 加入音乐干预记录
- 导出 CSV 后用 Python 做相关分析和可视化
- 设计正式危机处理流程

# 旧版：语音与音乐情绪分析小实验

这是一个纯本地运行的小网页原型。它可以上传音频，显示：

- 波形
- 声谱图
- 音高曲线
- 能量、平均音高、音高波动、过零率
- 一个基于简单规则的情绪/唤醒度倾向判断

## 怎么运行

直接用浏览器打开 `index.html` 即可。

如果浏览器限制本地文件，也可以在当前目录启动一个简单服务器：

```powershell
py -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 科研上的下一步

这个项目目前是“可视化 + 规则判断”，不是成熟模型。适合作为入门实验，后续可以扩展成：

- 用公开语音情绪数据集训练分类器
- 把每段音频的特征导出成 CSV
- 增加被试听音乐后的情绪评分表
- 用 Python 的 `librosa` / `scikit-learn` / `pytorch` 做更严谨的建模
- 做自己的语音风格、音高、能量控制实验
